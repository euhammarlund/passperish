What the envelope means

The near end is planetary. It is the moment when the surface stopped being hostile to any chemistry at all, and nothing about biology sets it. The far end is biological. It is the latest moment by which LUCA must already have existed, and it depends entirely on which evidence you accept. The difference between the two is the whole budget the chemistry has to work in.

How a required duration is built

Four terms, and only two of them are computed from measured chemistry

T1 is a scenario judgement you can scale. T2 and T3 are computed here from the handoff table, the temperature and the cycle, so changing the chemistry changes the duration. T4 is computed from population genetics and is the same for every scenario by design, which is why it sets the floor of the whole figure.

Chemistry becomes a probability

Each rung has a transfer time and a loss time. Their ratio is the Damkohler number, Da = tau loss divided by tau transfer. The probability that a species is handed on rather than destroyed is p = Da divided by (1 + Da). That is not an extra assumption on top of the handoff criterion. It is the handoff criterion written as a number between zero and one, so that it can be multiplied across rungs and turned into a waiting time.

Add new material

Elements, handoffs and references, as new papers come in

The model reads one JSON file, so extending it does not mean editing the app. Export the full model data, add your entries to the array you want to grow, then load the file back in here. Nothing is overwritten unless an entry has an id that already exists.

A file with a parameters key is read as a saved run. A file with elements, handoffs or references is merged into the dataset.
